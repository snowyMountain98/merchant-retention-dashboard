기업별 메인 화면 + 기업/가맹점 상세 화면 적용 가이드

적용 파일
- index.html: 메인, 기업별 요약/검색/위험 등급
- company.html: 기업 선택 후 소속 가맹점 목록/요약/기업 월별 추이
- merchant-detail.html: 가맹점 상세, 월별 승인/취소/부분취소 추이, AI 분석 근거
- assets/css/style.css, assets/js/*.js
- src/analysis/build_dashboard.py: 기업관리번호/기업명 및 가맹점별 12개월 이력 생성
- .github/workflows/analyze.yml: 새 HTML 페이지들을 Pages 산출물에 포함
- tests/test_enterprise_grouping.py: 기업/가맹점 계층 데이터 테스트
- README.md

GitHub에서 반영하는 방법 (로컬 실행 불필요)
1. https://github.dev/snowyMountain98/merchant-retention-dashboard 열기
2. 이 ZIP을 PC에서 압축 해제합니다.
3. 아래 파일은 기존 경로의 파일 내용을 교체합니다.
   index.html
   assets/css/style.css
   assets/js/dashboard.js
   src/analysis/build_dashboard.py
   .github/workflows/analyze.yml
   README.md
4. 아래는 새 파일로 추가합니다.
   company.html
   merchant-detail.html
   assets/js/company-detail.js
   assets/js/merchant-detail.js
   tests/test_enterprise_grouping.py
5. Source Control에서 변경 파일을 Stage하고 커밋합니다.
6. main 직접 커밋이 거부되면 ai-company-detail 같은 새 브랜치에서 커밋하고 Pull Request를 생성해 main에 병합합니다.
7. Settings > Pages > Build and deployment의 Source가 GitHub Actions인지 확인합니다.
8. Actions 탭에서 "AI Merchant Retention Analysis and Deploy" 실행이 성공했는지 확인합니다.
9. 사이트: https://snowymountain98.github.io/merchant-retention-dashboard/

중요
- 이 ZIP에는 실제 정산 엑셀 파일이 포함되어 있지 않습니다. 저장소에 이미 업로드된 원본 엑셀을 분석 입력으로 읽습니다.
- 원본 엑셀 파일은 읽기 전용입니다. 스크립트는 원본을 수정/저장하지 않습니다.
- Pages 산출물에는 index/company/merchant-detail 화면, 정적 자산 및 dashboard_summary.json만 복사하며 원본 XLSX는 복사하지 않습니다.
- 회사명 중복이 있을 수 있으므로 기업 식별 키는 기업관리번호입니다.
- Isolation Forest 점수는 이상징후 상대 점수이지 실제 이탈 확률이 아닙니다.
