네이버 키 발급: https://developers.naver.com/apps/#/register
Naver Search API의 News 검색을 신청한 애플리케이션에서 Client ID와 Client Secret을 발급받아 GitHub 저장소 Settings > Secrets and variables > Actions > New repository secret에 등록하세요. 이름은 정확히 NAVER_CLIENT_ID, NAVER_CLIENT_SECRET으로 지정해야 합니다.

GitHub Pages:
Settings > Pages > Build and deployment > Source = GitHub Actions

동작 범위:
- OpenAI 분석 입력은 기업 단위 집계만 사용합니다. merchant별 분석 prompt는 제거했습니다.
- Naver 뉴스 검색은 enterprise_id == '1999'에서만 수행합니다. 검색 대상은 사용자가 알려준 브랜드명 '스타벅스'입니다. 다른 마스킹 기업에는 검색 요청하지 않습니다.
- 월별 승인금액이 직전 달과 다른 모든 비교 가능한 월에 대해 뉴스 검색을 수행합니다. 승인금액이 변하지 않은 달은 검색하지 않습니다.
- Naver key가 빠져 있으면 전체 배포를 막지 않고 페이지에 키 미설정 상태를 표시합니다. 키를 추가한 후 Actions 재실행이 필요합니다.
- Pages 산출물에는 merchant-detail.html, merchant-detail.js 및 individual merchant JSON records를 넣지 않습니다. 원본 엑셀은 Pages 산출물에 복사하지 않습니다.
- 검색 결과는 가능성 있는 정황 증거이며, AI 가설은 인과관계의 입증이 아닙니다. 공개 출처 링크와 발행일을 함께 표시합니다.
